## Answer reference

1. `I = Q / t = 120 / 60 = 2 A`.
2. Ampere (A); an ammeter.
3. `R = V / I = 6 / 2 = 3 ohms`.
4. Current halves when resistance doubles at fixed voltage.
5. The long thin wire has greater resistance than the short thick wire.
6. `R_total = 2 + 4 = 6 ohms`; the same current passes through both.
7. Two 6 ohm parallel resistors have an equivalent resistance of 3 ohms.
8. Each appliance receives supply voltage and can be switched independently.
9. `P = V x I = 12 x 2 = 24 W`.
10. `E = P x t = 1 x 2 = 2 kWh = 7,200,000 J`.
